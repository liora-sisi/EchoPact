## 第一版做什么

1. **冻结对照。** 保留当前词面结果、测试语料、目标片段、候选数及字节预算，固定下游
   筛选和读包版本。停止为个别错题增加专用词典或分支；普通缺陷、权限和证据完整性修复
   仍可进行，但必须单独记录，并在两条对照路线中使用同一版本。
2. **索引原文片段。** 原始记录保持只读，独立派生索引可删除重建。先按记录，再按自然
   段落与模型真实输入限制切块；固定切块与重叠策略，记录原文偏移、角色、来源、房间、
   分支、时间和邻接关系。不能把整个房间压成一条向量，也不能静默截掉长记录尾部。
3. **本地语义补漏。** 先选并实测适合中文问句到原文片段检索的本地 embedding 模型，
   固定模型版本、维度、查询/文档编码方式、切块器、索引 schema 和原库代际指纹。
   首个 BGE 中文小模型已完成有限本机实测，尚未比较替代模型或验证全库/VPS 资源；
   第一版不新增向外部 embedding API 发送真实正文的通道。
4. **两路合流。** 原词与确定性日期路线保留；语义路独立找候选，先以 RRF 排名融合做
   可复测的起点，不直接相加两路原始分数。语义索引失效、版本不符或覆盖不全时明确
   报告并退回词面路，不能把缺索引当作没记忆。
5. **继续递小包。** 合流后才在已有上限内补相邻上下文、交给现有小管家筛选与打包。
   每个额外片段都计入候选与字节预算。不能借接向量之机扩大最终上下文负担。

向量索引是寻找原文的派生工具。摘要门牌以后可以作为额外索引和展示入口，不能成为
唯一的原文检索入口；摘要质量与向量召回质量分别验收。

## 会审建议的实施细化

- 身份、权限及已经确定的来源/时间限制在两路一致执行，原文回取前再次核验。
  模型猜测的日期、人物和事件关系不能直接升格为硬过滤；说话人也不等于事件主语。
- 按稳定记录编号汇合，但**不能只保留同一记录的第一个片段**；不同偏移的必要证据仍须
  保留。只去掉相同片段与已有规则证明的精确镜像，不按语义相似合并事实或冲突。
- 望舒建议来源/日期多样性配额。第一版先测重复占位与来源分布，不机械要求每种来源、
  每一天各占一格：明确限日期、限来源的题不能被这种配额改变范围或挤掉唯一证据。
- 向量相似度和 RRF 排名均不是事实置信度。名字被当成颜色属于读包时的无依据推断，
  保留在读包错题中，不能假设加向量便修好了。

## 最小对照与交付

先用合成材料验证切块、引用、过滤、回退和接线，再对冻结的真实只读样本做检索质量
比较。真实材料的模型外发仍遵守既有授权范围；本地检索验收本身无需外发正文。

主要两臂：A＝当前词面基线，B＝词面＋语义；可额外记录纯语义路作为诊断，但不借此
改变主要比较。两臂使用相同的语料代际、硬过滤、候选数量/字节上限、下游版本及最终包预算。
旧错题用于诊断；另冻结未参与调参的新自然问法。首次结果和每次修订均留存，
不可把调过的题重新称为独立留出题。

| 层次 | 本轮要回答的问题 |
|---|---|
| 找材料 | 同义换说法是否找到目标片段；精确名字、日期、来源有没有退步；噪声、重复占位、约束违规有多少 |
| 筛材料 | 已找回的目标和纠正有没有被模型丢掉；模型选中与本地相邻保护分开计数 |
| 读材料 | 主体、时间、计划/已发生、纠正和冲突是否解释正确；是否新增无依据断言 |
| 使用负担 | 最终包字节、查询延迟、索引资源与模型用量是否符合预先固定的预算 |

首轮题型覆盖同义表达、精确名词/日期/来源、近似主体干扰、长记录尾部、跨消息纠正、
无答案或证据不足。开跑前固定实际数量、预期证据和通过条件，避免看到结果后改门槛。

通过方向：留出题确有补漏，已核精确题无回退，约束违规为零，错误答案不增加，
短包保持有界。这里的“无回退”只描述固定验收集，不能宣称对所有未来问题作保证。
若候选改善但筛选/读包失败，分别报告，不把检索进步冒充整链毕业。

第一份交付是**可运行的隔离混合检索与同题比较报告**。该阶段不更换正式 MCP/Bot，
不批量生成摘要，不清理整个 legacy，也不增加新的交互功能。验收后再决定接入范围。

## 技术依据

- [Sentence Transformers：语义检索](https://www.sbert.net/examples/sentence_transformer/applications/semantic-search/README.html)：
  问句与文档进入同一向量空间，需根据短问题到较长段落的任务选择模型与编码方式。
- [Sentence Transformers：召回后重排](https://www.sbert.net/examples/sentence_transformer/applications/retrieve_rerank/README.html)：
  候选召回可能带入无关结果，寻找候选与后续筛选应分别验证。
- [OpenSearch：RRF](https://docs.opensearch.org/latest/vector-search/ai-search/hybrid-search/rrf/)：
  用排名融合避免直接比较不同量纲分数；它是可比较的起点，不保证在 Echo 上优于所有替代方法。

以上文档用于验证机制，不意味着为 Echo 引入 Elasticsearch 或 OpenSearch 服务。
