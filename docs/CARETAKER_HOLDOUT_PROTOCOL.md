# 查询管家：独立留出卷与评分约定

2026-11-25。根据外部评审建议和[中文输入勘误](SEMANTIC_INPUT_INTEGRITY.md)整理。
这是后续考试协议，**尚未创建或宣称通过三十至五十道真实盲题**。

## 原文与派生层

原始记录是出处底座，现有向量索引对原文片段编码；摘要门牌只能是另一个可撤销的辅助索引，
不能替换原始档案或唯一的原文检索路线。若未来试验摘要检索，要单列路线和成绩，不能混入
原文索引冒充原话。任何摘要事实都必须可回到当前身份可见的原文。

历史原文也可能是计划、误解、引用或已撤回的说法。出处可靠不等于内容永远成立；
仍须保留发言主体、时间依据、更正、冲突和不知道的边界。

## 出卷与隔离

- 目标四十题，可在三十至五十题范围内调整：建议三十道有答案、十道无充分答案。
  覆盖口语换说法、长记录尾部、跨消息更正、时间线、角色关系及互相冲突的证据。
- 真正盲卷由未参与本轮调参的独立评审者出题并保管答案；先封存实现、提示、模型、
  索引和配置，再揭卷运行。开发者自己看到答案后继续调参的题只能叫开发题。
- 按现有试验清单排除使用过的问句、原始记录、同房相关分支及镜像来源。
  仅把旧题换个说法不算新盲题；无法确认是否使用过的材料要标记，不能保证“绝对从未见过”。
- 必须固定实际检索语料，不能只收金标准附近的原文、删除干扰项来提高分数。
  当前六百二十二条诊断子集不满足正式全库验收要求。
- 首轮答卷、输入文字回执、费用和失败都保留。看过结果后，该卷转入长期回归集；
  后续调参后需新的留出卷，不能反复刷同一张卷冒充泛化提升。
- 真题、答案及原文留在私有目录；仓库只存格式、合成例题和汇总。
  外发范围及费用单独核准，协议本身不是上传真实材料的许可。

## 每题至少标什么

| 项目 | 必须说明的内容 |
|---|---|
| 原问与范围 | 自然问法、固定参考时间、来源/身份限制、完整 Unicode 文字摘要 |
| 核心答案要点 | 哪些事实是必须的，哪些只是可选细节；答案不发送给待测模型 |
| 必需证据组 | 原文指向、逐字窗口、允许等价的镜像记录；不能靠同一原文重复占名额 |
| 时间关系 | 可靠事件时间、记录时间、先后顺序及不可推断的地方分别列清 |
| 冲突与更正 | 哪些旧说法必须保留为背景，哪些已经撤回，哪些尚不能判断 |
| 允许缺失 | 何种情况下只能说“不确定/证据不足”，可以交代哪些已知事实 |
| 禁止结论 | 角色倒置、把计划当完成、把没找到说成没发生等本题具体错误 |

无答案指的是在冻结且当前身份可见的资料中没有充分证据；不是证明现实中没有发生。

## 评分线及口径

1. **Top-3 命中率至少 85%。** 分母只算有答案题；前三个交付证据组至少包含一组有效
   金标准证据才记命中。同一原文的重叠片段或镜像不重复占名额。
   三十道有答案题至少二十六题命中才达到门槛。该分数不是完整答案覆盖率。
2. **无答案题守住证据不足的比例为 100%。** 不要求生硬拒绝所有内容，可以说明已知部分
   和缺口，但不能补造确定答案。十题全部守住才通过这一批，不宣称未来所有问题均能做到。
3. **关键时间线、角色及冲突不得反转或隐去，确定事实必须有有效原文支持。**
   另计每题所有必需证据组的覆盖和最终回答完整性；不能用“前三条碰巧中一句”掩盖漏掉更正。
   接收方回答与候选检索分别验，不能只查引用编号存在就算理解正确。
4. 同卷、同身份、同语料、同输出预算比较旧路线和新路线。另报原始候选排名、
   最终短包字节数、延迟、调用次数、费用以及超时回退。所有题都回答“不知道”不能通过第 1 条。

## 排查与接入次序

先查输入文字与来源是否完整，再查切块是否覆盖尾部和边界、候选在各路的原始排名、
合流前后在哪里丢失、初选与邻文交付是否遗漏。输入损坏、模型适配、候选截断等也可能
造成排序问题，原因不限于切块或 RRF。每次只改能由证据支持的部位，保留同题对照。

目前不因旧的第 286 名引入重排；那是损坏输入的成绩。必要的候选、分块和合流证据
查清后，才讨论是否需要另一个排序模型，并做同预算对照。

正式接入还需全量索引及资源、约束路由、失效回退和接收方质量验收。
这份协议不扩大当前索引的五千记录上限，也不开放 MCP、Bot 或 VPS 的模型路线。
