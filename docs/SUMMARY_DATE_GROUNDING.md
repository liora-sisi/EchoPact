## 两种办法与实际结果

两批都复用既有三道合成窗口，共 5,327 原文字符；判卷目标留在本地。
每批三次调用，均收到完整答卷，没有自动重试。这些题已经参与过开发，**不是独立盲测**。

1. **V3：让模型抄日期凭据，未通过。** 模型输出日期、事件短语、原句和片段编号，宿主检查
   引文逐字一致、日期是否出现及是否与事实共享短语。实际答卷仍会往所谓原句里添年份，
   也会违反短语约定。日常题另有指向自身的事件关系，原运行先因该关系拒绝答卷。
   另两题有 3 / 29 项日期凭据诊断；它们含多个约定诊断，不能算作 3 / 29 个独立编造事实。
   离线补查日常题得到 5 项日期诊断，单独留档，没有回填或改写首份报告。
2. **V4：日期索引由宿主生成。** 在原文中识别有效完整年月日，保存日期出现的位置、所在记录、
   精确原句及片段指向。相同日期出现在两处仍是两个编号。模型只选编号或空值，由宿主填入
   完整日期并附原句。原文只有月日时保留月日，不能拿消息时间或附近年份补满。
   规则明确区分取消决定日与原定活动日，但模型仍可能选错角色，不能自动放行。

V3 保留为可复现失败版本；V4 是试验候选。原模型答卷始终保留，派生的旧格式阅读稿与后台凭据
分别保存并绑定指纹。日期凭据不塞进阅读短卡；它们属于后台核验档案。

## 日期检查的边界

- 只识别当前支持的中文完整年月日和 ISO 日期；不声称已经实现通用时间理解。
- 同一完整日期恰好跨两个相邻片段时，新版本可以拼回；不能跨记录或跨缺口拼接。
  V1/V2 的旧核验行为保留，旧冻结试卷与档案不会随这次修复悄悄变样。
- 旧日期出处拦截只针对已明确给出新日期、且旧日期不同的纠正：当前事实再引用该旧出现位置
  会报错。其他独立出处恰好也是同一天仍允许。它不能推断所有过期关系。
- 日期存在、原句准确，不代表选对事件或时间角色。历史计划能被保留，但不能误作仍在进行的安排。
- V3/V4 诊断档案与旧阅读稿分开；运行报告遇到日期错误标记需要修稿。所有预览仍未批准，
  没有把这些材料接到正式摘要柜或查询接口，也未建立生产级审批链路。
