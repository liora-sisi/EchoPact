# 查询管家：适用范围与对象纠正校准

2026-11-20。查询筛选器和对象复核提示升级到 v5；仍为隔离试验，未接入正式 MCP 或 Bot。
这是[真实旧题考试](CARETAKER_REAL_EVALUATION.md)之后的诊断校准，不是旧错题已经通过的回执。

## 问题与改动

真实考试暴露两类错误：把某次安排当成通用约定；看见对象纠正却丢掉，或在对象仍未对齐时说充分。
v5 在每次请求的固定指令中要求模型核对问题的适用范围，保留原话中的限定条件，并区分配件与完整对象。
对象对应被推翻、但未补齐时保留纠正和 `object_identity`；同一组对象确已澄清时，仍可判充分。
这没有训练模型权重，也没有在本地按关键词或特定案例名称强制改判。

输出契约、原文唯一定位、原始记录、候选/字节上限和回退路径不变；v4 的相邻原文保护继续保留。
查询管家与导入时预写摘要仍是两项工程，本轮没有生成真实档案摘要。
