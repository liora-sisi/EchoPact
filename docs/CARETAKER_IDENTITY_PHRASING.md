# 对象纠正：同一材料换问法的诊断

2026-11-20。对象复核为 `echo-object-evidence-review-v6`，通用筛选器仍为 v5。
本轮针对[此前真实复考](CARETAKER_SCOPE_CALIBRATION.md#后续同卷真实复考)中“问搭配时漏选对象纠正”的问题。
仍为隔离试验，正式 MCP、Bot、原始数据库和导入侧摘要未启用这项改动。

## 改了什么

对象复核指令要求先核对问题所指对象，再筛选属性。即使问题只问颜色、材质、搭配或区别，
改变描述归属、区分整体与配件的纠正，也可能是必要证据；对象未对齐时应引用并保留不确定性。
同时排除只有道歉、无关对象改名和指挥模型分类的文字。对象已被问题明确点名时，仍应允许充分回答。

只改每次请求中的对象复核指令，没有按真实名称、题号或关键片段硬选材料。
输出契约、来源核验、逐字引用、相邻原文保护、字节限制和回退机制保持不变。

## 四道固定虚构对照

四道开发诊断题使用**完全相同的六张候选和来源顺序**，仅问题变化：

| 问法 | 预设重点 | 实际结果 |
|---|---|---|
| 对象未点名，问怎么区分 | 保留无属性细节的身份纠正，并报告对象不明 | 通过 |
| 同样未点名，问面料和口袋 | 不能因只问属性就丢掉身份纠正 | 通过 |
| 明确点名两个对象 | 按已核属性回答，不一律报歧义 | 通过 |
| 明确点名另一对对象 | 不把无关纠正或道歉升级为所问对象的证据 | 通过 |

既有 GPT-5.6 实际调用四次、零重试，预设检查 **4/4**。全部指令注入候选均标无关。
题目、原话、标签和关键引文在调用前冻结。部分不入选文字预先允许 `context/irrelevant` 两种分类；
只有这两种不入选标签可等价，绝不允许把要求 `answers/uncertain` 的证据丢掉后仍判通过。
旧试卷不含该标注时评分行为不变；标准答案和允许标签均不进入模型输入。

这是已知失败后设计、共享材料的开发对照，不是四道独立盲测，也没有旧提示同题付费对照。

## 两道真实旧题与一个零调用控制

两道对象旧题继续使用先前同问句、同 24 段/6,788 字符、同匿名来源顺序，只有对象复核提示换为 v6。
各实际调用一次，不新增检索、问句规划或私人摘录。比较基线是已保存的 v5 回复，旧卷不覆盖。

| 对象问法 | v5 已选中关键纠正 | v6 已选中关键纠正 | v6 原定诊断检查 | 当前目录 / v6 短包字节 |
|---|---|---|---|---:|
| 旧问法 | 是 | 是 | 未通过，仅缺口分类不符 | 9,142 / 10,924 |
| 搭配与区别问法 | 否，本地上下文保住 | 是 | 通过 | 9,797 / 10,539 |

本次两题的关键纠正都在**模型所选原话**里，已核完整目标均可见，来源、角色、记录时间和字符位置核对通过。
两题都报告 `ambiguous`，本地也仍 `needs_more_evidence=true`；未对“究竟是哪一对对象”给出完整答案验收。
两份短包仍大于现行短目录，不能宣称整体上下文负担已经改善。

旧问法返回 `gap=conflicting_evidence`，与调用前固定的 `object_identity` 预期不同，因此严格诊断仍记 **1/2**。
材料同时包含未点明的对象和互相矛盾的旧描述，需要复核单个缺口字段的优先次序或表达方式。
保留这次分歧与未通过成绩，不在看到结果后改变标准；关键纠正保留和原因分类分别计量。

通用手账路径的请求与先前 v5 完全相同，只重放已保存答卷并核对出处，零新增调用，原诊断仍通过。
不能把这个控制写成第三次新模型通过，也不能把两个旧题的单次结果当作稳定性或生产准确率。
