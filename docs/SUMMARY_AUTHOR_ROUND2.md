同一提示、原文、证据编号及响应结构；评分目标、禁错项、分组标签不进入模型输入。
新题不是独立盲题：出题、提示制定和语义复核仍由同一助手完成，成绩必须按三组分开报告。
不能把已调整过的旧题或这次开发题称为真实留出卷。

长题含日常细节和跨消息更正；不在原文中插入标准答案或要求模型执行评分指令。
来源保持逐字片段，包含每条原记录编号与位置。私有片段仅有局部编号、原消息时间未知，
不冒充从 Echo 独立核验过的完整事件。

## 第二轮共同约定

- 同一计划只保留最终状态。取消以后不再另列仍有效的计划；被推翻的断言放历史字段。
- 原因问句属于猜测。回答问题可标为直接澄清，不能为了填纠正字段伪造曾经确认的旧断言。
- 日期、对象与更改依据分散时一起引用。已完成准备和尚未发生/取消的活动分别判断。
- 省略对象和代词指向不清时保留歧义，不自行补生理原因、对象身份或材料没写的细节。
- 长题可列至多八条事实，给工程、生活、感受留出空间；首轮六条上限和首轮答卷保留不改。

首次离线草案沿用六条事实容量，检查后发现不足以同时容纳长题的独立事实，已在调用前
另存八条容量的冻结版；原文字数、发送目的地和费用上界均未改变。
两家格式接法仍有差异：OpenAI 用 Responses 严格结构，DeepSeek 用 JSON object；
这些是实验条件，不据此声称完全相同的推理计算量。

## 验收与减重

先核对语义：人物方向、当前/历史、日期关系、否定、感受、未知边界与完整出处。
格式正确或引用编号有效，只证明机械约束，不能代替语义忠实。
显式拒答、空白、截断、漏题、字段错误和事实错误分别记录；任一组缺测不算整体合格。

对三道长题同时记录：

1. 原文字符数，以及事实正文＋历史正文＋未知项的总字符数；目标比例不超过 60%。
2. 包含字段与引用编号的完整结构字节数，以及原始正文的 UTF-8 字节数。
3. 保真审阅结果。即使比例很低，遗漏关键事实、拒答或空白也不能成为成功的减重。

这些字符与字节指标不是 token 账单，也不是最终 MCP 交付包的大小。
本轮尚不验证检索增益，不将三段六百余字的结果外推到整房长文或二十多万条记录。
