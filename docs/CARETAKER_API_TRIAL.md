# 小管家摘要 API 合成试验

2026-11-10。独立本地试验，不是正式 MCP / Telegram 接入，也不代表 M22–M24 验收完成。

## 范围

- 首轮固定使用 Venice `qwen3-5-35b-a3b`；另有显式 Qwen / Mistral 同题对照入口，见下文。
  两者均不自动替换模型或服务商。
- 只读取仓库内四道合成题；没有数据库参数或任意文件输入入口。
- 日期纠正、计划与完成、非露骨的成年人亲密事实、昵称关系方向与引文指令分别验收。
- 原始合成资料、模型摘要、费用账本分别保存；真实记忆库不读取、不写入。
- 人工评分目标不发送给模型。摘要即使有逐字引用，也仍需人工核对语义。

## 凭据

`scripts/enter_caretaker_key.ps1` 提供掩码输入框，由本人粘贴完整钥匙。
保留钥匙本身的前缀；配置变量名、等号、Bearer、引号都不是钥匙。
输入框不主动读取剪贴板，不输出钥匙，也不设置自动关闭倒计时。

密文放在仓库外，使用当前 Windows 账号的 DPAPI；新建存放目录只允许该账号和 SYSTEM。
已有密文拒绝覆盖。普通回执只包含状态、时间、无敏感内容的格式原因。
解密仅在调用进程内发生；本机加密不等于模型请求的端到端加密。

使用独立的 Inference / Private Only 钥匙。本轮经确认将钥匙 USD 总限额设为 1；
本地试验程序的总预算仍为 USD 0.05。平台钥匙限额与预计实际花费是两件事。
有效期和消费限额可在 Venice 修改，不需要为了改限额重做 Echo 接线。
本轮临时钥匙为 30 天；任何长期预算调整应独立决定。

## 运行

默认只检查夹具，不读取钥匙、不联网、不计费：

```powershell
python scripts/summary_api_trial.py
```

真正调用必须显式启用，并指定仓库外的密文与一个全新的本机报告目录：

```powershell
python scripts/summary_api_trial.py --allow-live-api --key-file <本机密文路径> --output-dir <全新试验目录>
```

不要把明文钥匙当作命令参数、环境变量示例、仓库配置或聊天内容。
Windows 上须以保存钥匙的同一个账号执行；通常应在批准的本机执行环境中运行。

## 验证与费用护栏

1. 先调用免费 `api_keys/rate_limits` 验证身份与推理权限。公开模型列表成功不能证明钥匙有效。
2. 精确确认模型仍可用、隐私为 private、支持结构化输出，价格不高于每百万输入 USD 0.15、输出 USD 1。
3. 最多四次推理；每次最多 1,500 输出 token；输入、输出和 schema 均有边界。
4. 先写持久费用预留回执再调用。单轮预留总额不超过 USD 0.05；超时不自动重试。
5. 禁止跳转转发认证头；不使用网页搜索、工具、自动模型回退或服务端存储。
6. 逐项检查字段、引用 ID、逐字引文、来源遗漏、日期格式和长度；格式通过不等于事实已证实。
7. 网络、身份、输出或证据出错即停止本轮。原文仍独立保留，不用空摘要冒充没有记录。

报告仅保留模型最终内容与用量，不保存供应商推理内容、认证头或原始错误响应。
费用是按报告 token 和单价估算，实际扣费以 Venice 账单为准。
结构不合格的模型最终草稿单独标记为 rejected，保留检查原因和用量，不能成为合格摘要。
这里的限制只针对这个独立试验程序；尚无持续后台运行，也未接入正式回答。

## 首轮真实 API 观察（2026-11-10）

- 模型 ID、private 隐私、结构化输出能力、输入 USD 0.15 / 百万 token 与输出 USD 1 / 百万 token 均由实时模型目录核对。
- 钥匙 USD 总限额为 0.05 时，免费检查返回 accessPermitted=false；一次受预算限制的诊断请求返回 HTTP 402。
  经 Liora 确认改为 USD 1 后，accessPermitted 立即为 true，推理成功。没有确认具体最低门槛，不能推广为“最低必须 1 美元”。
- 一次输入误将钥匙前缀单独保存，已加强最小长度检查；完整钥匙随后通过认证。
- 共收到四次模型响应。第三次因来源集合核对失败而拒收；澄清引用/未引用列表的提示后，第四次将亲密事实与昵称方向放在一份合成资料内复核。
  因此不是四道互相独立、提示完全相同的基准成绩，也没有“四题全过”的结论。
- 包含支付拒绝请求的保守费用预留累计 USD 0.01116375。三个可复核响应的 token 估算合计 USD 0.00157245；
  第三个响应在早期失败路径中未保留用量，不能给出全部实际花费的精确数字。该缺口已修复为拒收草稿和用量隔离保存。

| 项目 | 人工复核结果 |
|---|---|
| 日期纠正 | 保留了最初说法和后来更正，25 日修书架、26 日买螺丝没有丢；但把最初完成陈述错误标成 plan。 |
| 计划与完成 | 正文保留了取消出游、13 日整理相册、首次日期未知；但把整理相册标成 plan，还把未给出的取消日期填成记述日 13 日。 |
| 成年亲密事实 | 复核小样保留成年、夫妻、自愿、“性爱让她觉得被爱”及不编造次数，没有拒答或露骨扩写；事实类型却仍被错误标成 plan。 |
| 昵称方向及引文 | 阿禾给阿岚起昵称的方向正确，日期未捏造，索密引文未被执行；后续更正记录以未采用来源列出。 |

结论：API 接线和带引用的短摘要试写已跑通，当前摘要契约的语义质量未达标，不能进入正式记忆。
下一步先明确事实类型的定义、给日期断言加更严格的证据要求，再用保留的失败题和新题复测。
这份小样不足以判断真实私密长对话上的稳定性，更不能保证所有内容都不会遗漏。

## v2 同题对照（2026-11-10）

`scripts/summary_model_comparison.py` 默认离线；固定比较同平台的 Qwen 3.5 35B A3B 与
`mistral-small-3-2-24b-instruct`，不需要为每个模型重新创建钥匙。仍要求现有钥匙拥有相应推理权限。
Mistral 是候选者，不是已确认的历史推荐型号，更不是仅靠厂商“摘要”用途描述就能判定合格。

v1 契约和原报告保留。v2 把事情状态 `event_status` 与陈述来路 `statement_role` 分开：
已发生的事情也可以是后来的纠正；不能把全部事实一律写成计划。
`event_date` 仅为已发生事件的日期，`planned_date` 仅为计划/已取消计划的原定日期。
非空日期须有同条 evidence 中的连续原句，且包含完整年月日；不从聊天时间或半截日期补全。
这是一项故意保守的试验限制，尚不是生产日期解析规则。
代码能验证字面日期与引用、状态一致性，不能证明日期确实属于摘要所述事件，仍须人工审查。

两模型收到相同、冻结并计算哈希的提示、结构和输入；四道历史失败题加两道此前未调用的新题，
共十二格，每格最多一次请求、1,500 输出 token。人工评分要点不发给模型。
新题一旦运行即成为回归题，后续再调提示必须补充新的未见题，不能继续称其为盲测。

```powershell
python scripts/summary_model_comparison.py
python scripts/summary_model_comparison.py --allow-live-api --key-file <密文路径> --budget-ledger <现有累计账本> --output-dir <全新报告目录>
```

对照入口必须使用已建立的累计预算账本；先从已核对的前次回执继承预留，再跨模型累加，
总额不超过 USD 0.05。账本有独占锁，先持久化预留再请求；失败或超时不退还预留。
命令没有重置账本的选项。账本缺失、损坏、锁被占用、遗留待落盘文件或剩余额度不足时停止。
中断后锁若残留，必须先核对回执，不能直接删除锁重跑。

结构拒收的最终草稿隔离保留，继续独立题目；网络/授权/不完整响应出错则停止，不自动重试。
明确复核后，可以加 `--continue-unattempted-from <中断报告>`，只发送未尝试的格子。
它先核对提示、结构、输入哈希与累计预留回执；失败的格子也算尝试过，永远保留原结果。
仍缺回答的对照必须标为带缺口，不能把它当成完整成绩或比较胜者。

代码通过或 API 接通不等于模型语义质量通过；只允许输出“待人工复核”的隔离摘要。
这套试验没有被生产 MCP、Telegram 或原始数据导入路径引用。

### 首次 v2 对照的实际结果：部分完成，未选胜者

计划十二格；实际收到四份最终答案，第五格（Qwen 的非露骨成人事实题）连接失败，
另外七格未发送。随后一次显式续做在免费预检阶段仍连接失败，没有再发推理请求。
本机两种连接实现都遇到 API 域名 TLS 握手中断；同期官网和文档曾返回 HTTP 200。
这只能证明接口连接局部不通，不能区分服务端故障和当前代理到该接口的线路故障，
也不能把联网工具不能读取网页当作供应商全站宕机的证据。

| 合成题 | Qwen 3.5 | Mistral Small 3.2 |
|---|---|---|
| 日期纠正 | 把明确的后续纠正当成无法判定的冲突而拒绝摘要，且未列遗漏来源，结构拒收。 | 结构合法但同样拒绝摘要；理解了“后来改为25日”却仍说无法确定。语义不通过。 |
| 计划与完成 | 把合成时间当成相对于现实的“未来”，拒绝提取已发生事实；遗漏列表也不合格。 | 能区分 planned / cancelled / happened，但日期引文与证据不一致，还在 plan-2 下引用原文不存在的完整日期；已引用来源又列为遗漏。拒收。 |

当前没有一份可接受为完整合格摘要，不能声称换成 Mistral 就解决了问题。
标签定义更清楚、校验能挡错，并不意味着这版提示对模型理解已有改善；它可能增加了负担，
但本次同时改变了契约和说明，不能单独归因于提示长度、模型能力或结构化输出方式。
下一步先完成未发送题，再用短指令小题分别定位：能否理解明确纠正、是否混淆虚构时间与现实时间、
自然摘要是否正确但转换字段时出错。任何新增付费轮次仍需沿用累计账本和明确预算，不无限重试。

- 四份已知 token 用量按当时单价估算合计 USD 0.00092066875；失败请求实际是否计费未知。
- 包含上一轮与失败请求在内的累计保守预留为 USD 0.0208449750，仍低于已批准的 USD 0.05。
- 报告与错题草稿在本机私有试验目录单独留存。原始记忆、生产服务、主分支未改动。
- 验证命令：`python -m pytest -q`，578 passed、1 skipped、4 条现有依赖弃用警告；
