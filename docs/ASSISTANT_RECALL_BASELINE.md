## 已经能做什么

`scripts/assistant_recall_baseline.py` 在本机调用现有只读 MCP gateway，记录：

- 第一句自然问题与后续追查各自的返回量、底层检索轮次；
- 到第几次工具调用累计收齐已经核对的原话，以及到那次为止累计返回多少字符；
- 原包与现有 M21 短摘录中的目标是否还在，不能只凭记录 ID 相同算通过；
- 主结果、相邻原文、短摘录分别计分；后来复述和派生 claim 不冒充目标原文；
- 来源、房间、记录时间、身份与语料指纹，便于以后复测。

这是**固定问法的诊断回放**。第二轮的关键词由复核者事先提供，标记为
`reviewer_diagnostic_clue`；没有实现模型规划，也不能把“知道关键词后命中”
当成模型自动听懂。第一轮的检索器只收到原问、limit、参考时钟，不收到答案、
目标记录 ID 或诊断线索。

## 可重复的私有输入

题目文件与输出目录均位于本 checkout 外的私有存放处，不进入项目 Git。
真实问题来自已报告的问题类型的重新表述，标为
`reconstructed_from_reported_issue`，不冒充原错题逐字回放。已有原始错题包不改。

题集格式为 `echo-assistant-recall-cases-v1`，包含：

- `corpus_sha256`：离线 SQLite 代的完整文件指纹；不接受 WAL / journal 活跃库；
- `reference_at`：带时区的固定问句时钟，相对日期不随重跑日期漂移；
- `cases`：最多 12 题，每题最多三轮；第一轮 `natural`，后续仅为已标识的诊断线索；
- `targets`：每个目标指定记录 ID、来源、房间、整条内容指纹、复核后的逐字片段；
- `reviewed_by`：有目标时必填，无目标时留空并明确 `unscored`。

执行前逐个核对目标真实存在、当前固定身份有权读取、原文指纹和逐字片段一致。
目标列表不穷尽所有正确答案；未标注结果只是“未标注”，不是已判定无关。
`all_targets_visible` 仅表示这些已核原话出现，不表示整道问题的答案已经完整、正确。

```powershell
python scripts/assistant_recall_baseline.py `
  --cases <私有已复核题目.json> `
  --db <离线只读SQLite> `
  --agent-id <固定读取身份> `
  --output-dir <全新私有结果目录> `
  --limit 10
```

可显式指定现有 `--speech-policy`，其指纹进入报告；默认不加载私人改写表。
结果不覆盖、不自动重试。输入、开始回执、最终报告分别保存，失败只留安全错误码，
不生成成功报告。最终报告不复制查询或召回正文，仅含来源信息、原话指纹和统计。
执行前后检查原始库、实现文件和语音映射是否变化；实现源码指纹及 Python / SQLite
版本一同冻结。这里的私有目录沿用本机已有 Git 忽略规则，不修改权限或备份设置。
