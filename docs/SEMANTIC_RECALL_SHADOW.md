# records-v1 本地片段向量：首轮隔离试验

2026-11-22。已完成模型下载、CPU 离线推理、独立索引与同题候选对照。
**尚未接入小管家整链、MCP、Bot 或 VPS。** 本阶段承接
[混合召回施工计划](HYBRID_RECALL_SHADOW_PLAN.md)，不是 M24 正式验收。

本文保留第一阶段结果。随后已完成[原文窗口到筛选短包的接头试验](SEMANTIC_WINDOW_HANDOFF.md)，
仍未启用完整小管家生产路线；下列“尚未证明”描述的是本阶段停点。

## 实现及边界

- 模型为 [BAAI/bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5)，
  固定 revision `7999e1d3359715c523056ef9478215996d62a620`，512 维。
  只下载 safetensors 及配置/分词文件，合计 96,378,296 字节；不加载远程代码。
  每个文件有 SHA-256 清单，加载前复核。下载体积不代表运行内存需求。
- 查询使用模型指定的中文检索前缀，原文不加前缀，向量归一化。
  按单条原文自然断点切块，至多 360 字符、重叠至多 48 字符，并实际检查分词长度，
  超限继续缩小；没有把整间房压成一个向量或静默丢弃尾部。
- 新 SQLite 派生索引只保存向量、记录编号、字符起止偏移和版本信息；原文及来源
  仍从 records-v1 回取。不复制成另一份事实库，不按语义相似度合并记录。
- 索引绑定固定身份、模型、切块器和整个源快照指纹。只接受无 WAL 的冻结快照；
  活跃身份与可见性在查询时重新核验，查询中原库变化也拒用旧索引。
  回退重新读取现行权限，不能继续递出撤权前缓存的候选。
- 原词面与语义各取至多 K 个候选，RRF 排名融合后仍取 K 个记录；同一记录保留
  至多两个匹配偏移。相似度、融合排名与事实置信度分列，不能互相冒充。
- 已被现有问句守卫识别的日期、来源、主体关系、原话、编号、否定等约束题，
  整题保留原路线。这个守卫是有限线索识别，**不是完整自然语言解析器**。
  索引缺失或失效也明确回退，不把故障解释成“没有记忆”。
- 本次采用 NumPy 精确余弦扫描，最多 5,000 条可见记录、20,000 块、20 个候选；
  超限报错，不悄悄只取前一部分。没有启用 legacy Chroma，也没有建立常驻服务。

## 实际模型结果

冻结了首次结果；后续仅补实现指纹、试卷保存、输出目录保护和查询中撤权检查，
没有按答案修改问句、语料、模型、分块或排名。复验结果相同。

| 试卷 | 原词面 | 词面＋向量 | 限制 |
|---|---:|---:|---|
| 合成开发样本：12 条记录，6 个已标目标，Top-3 | 1/6 | 6/6 | 小样开发题，不能当生产准确率 |
| 真实旧题诊断：622 条冻结记录，4 个已标目标，Top-10 | 1/4 | 2/4 | 从旧检索候选与已知目标构建，既非全库，也非独立留出题 |

合成卷共十题，还包括三道约束对照和一道无答案题。三道对照去除试验轨迹后
与原输出逐项相同。无答案题仍能找到“相对最近”的候选，因此不能用检索排名
宣称答案充分，后续筛选必须会拒绝。

真实六问中，一道手账旧问法从漏掉目标变为找回，且已核原句确实可见；原本
命中的换问法仍命中，两道复杂物品问题仍未命中目标。日期/来源等原路线对照不变。
所有比例只计顶层目标记录，不能把邻接文本或部分目标命中算作整题答全。

首次真实样本索引为 1,122 块，用时 22.86 秒；最终同题复验为 23.84 秒，
索引文件约 4.62 MB，三道实际走向量的查询耗时约 45–47 毫秒。
模型预热后加载约 3.44 秒；首次冷启动曾约 102 秒。
这些是当前电脑的小样记录，未测峰值内存，不能外推全库速度或 VPS 承载能力。

每份本地报告包含源库/模型/试卷/实现指纹、两臂原始结果、候选数、字节数、耗时
和回退状态。首次与复验分开保存。真实试卷、原文包和索引均在仓库外私人目录，
不提交到 Git。原始真实库与诊断副本的前后指纹相同。推理禁用网络连接，
没有调用 OpenAI、Venice 或其他模型 API，也没有产生模型调用费用。

## 还没有证明什么

目前两臂的顶层记录数上限相同；候选审计包的字节量**只测量，没有等额限制**。
真实审计输出仍可超过 100 KB，它留在本机，不能直接递给助手当新的小包。
尚未完成施工计划中“相同候选字节预算＋相同最终包预算”的完整比较。

长记录尾部在索引里保留并返回匹配偏移及内容指纹，但网关正文仍受现有字符上限
限制。下一步要按这些偏移读出有界原文窗口，再交现有筛选器及无损短包；
不能仅凭父记录进入 Top-K 就声称关键尾句已交给小管家。

此外还未做：未参与调参的真实自然问法考试、全库增量构建/内存验收、镜像及
重复占位质量比较、下游完整答案评估、VPS 资源核验。模型也尚未与其他中文
embedding 模型同卷比较，当前选择是可运行起点，不是已证明最优。

## 运行与验证

已有 Python 环境提供 sentence-transformers、PyTorch 和 NumPy，本轮未安装或
升级依赖。实际验证环境为 sentence-transformers 5.6.0、torch 2.12.1、NumPy 2.5.0。
模型下载与数据库试验是分开的两步，前者不读取私人库：

```powershell
python -m scripts.prepare_local_embedding --destination .tmp/models/bge-small-zh-v1.5-7999e1d3
python -m scripts.semantic_shadow_trial --model-directory .tmp/models/bge-small-zh-v1.5-7999e1d3 --output D:\AI-workspace\.private\EchoPact\semantic-trials\run-001
```

下载只访问固定公开模型，不使用账户令牌。已有模型清单不能覆盖；试验输出必须
使用仓库外的新目录，即使合成 CLI 也按此要求执行。试验不覆盖旧报告或已有索引。
通用模型机制测试使用合成向量，只证明接线；上表另外运行了真实下载模型。

完整回归：**1,067 passed，1 skipped，4 个已有依赖弃用警告**。
新测试覆盖完整分块、尾部锚、跨身份拒绝、权限变更、坏索引、模型不符、
约束题不走向量、缺索引回退和候选数上限。曾因测试临时目录置于仓库内部触发
28 项既有私有产物保护；未放松保护，改用仓库外临时目录后完整通过。
