# M22 问句小管家：本地影子小闭环

2026-11-10，接续助手验收基线 `38416ea`。
工作分支 `codex/query-caretaker-shadow-2026-11-10`。
主要使用者仍是 Elion；目标是自然找记忆、少带上下文，不以 Bot 聊天呈现代替召回质量。

## 实现范围

```text
原问题 → 固定身份只读原路线（保留）
       → 适用范围检查 → 模型只看问句，挑主题词与问题类型
       → 本地校验 → 最多两个追加查询 → 本地带出处短摘录
```

- `query_caretaker.py` 核心不依赖供应商。模型回调只收到一个问句字符串；
  没有数据库正文、预期答案、私人别名表、记录 ID、历史聊天或工具权限。
- 模型只能提交 `status / intent / topic_terms`。主题词必须在原问中原样连续出现，
  长度和数量受限；不允许猜名字、日期、答案或配置身份。
- 追加查询使用这些词和通用的问题类型模板；保留原问，并明确追加路线。
  日期、来源、否定、原话、角色和最早/最近等已识别限制暂只走原路线。
  这是保守的原型路由，不声称已覆盖所有自然语言限制，复杂问句仍待正式验收。
- 每次最多一次 planner 回调、两个追加 gateway 调用、每次 Top-10；共最多三次
  gateway 调用。各自原有的 adaptive 内部轮次仍有界。失败的尝试也计入调用次数。
- 附加路线不得产生新的日期过滤。身份和数据库由调用方固定，模型不能改动。
- 短包最多六条、2,400 字符原文、整个 JSON 最多 8,000 字符。摘录围绕主题词
  选连续窗口并保留偏移、记录 ID、来源和房间；不是模型改写的摘要。
- 相同记录 ID 复用；相同 ID 内容变化则退回原路线。不做语义自动合并。
  排序仍只是确定性的词面辅助，不证明事实正确、证据齐全或事件日期。
- v2 短包不再用完全没有原样主题词的记录补足条数；分别计数主题不符与容量剔除。
  没有原样主题候选时返回 `no_literal_topic_evidence`，保留原路线与各轮调试结果。
  这只是词面线索不足，可能来自长短称呼差异，不能解释为“记忆不存在”。
- 无 Key、预算不足、超时、拒答、非法计划或追加召回失败时，保留原包与原有 M21
  短摘录。原始数据、正式 MCP、Bot 和 M21B 摘要柜均不改变。

核心结果中的 `original` 和 `passes` 供本机复核，消费短结果须取 `brief`；
不能把整个影子调试对象再次倒进助手上下文。正式入口尚未接线，也没有启用自动摘要。

## OpenAI 接法与预算

独立适配器 `openai_query_trial.py` 复用已有受限传输和 DPAPI 凭据，模型仍是此前
选定的 `gpt-5.6-sol`。Responses 严格 JSON、low reasoning、700 输出 token 上限，
`store=false`，不启用工具或接续旧响应。只保存最终计划和用量，不保存推理项。
关闭响应存储不等于宣称账户已有零保留协议。

实现依据：[结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)、
[GPT-5.6 Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol)。价格仍按此前
核验的每百万输入 USD 4 / 输出 USD 20 保守预留，2026-11-30 后要求重新核价。

沿用原 OpenAI 累计账本，不开新账逃过旧上限，不修改平台钥匙或消费权限。
请求与配置先冻结，单次意图和费用先持久化再调用；失败不自动重试，恢复复用已有结果。
旧的 900-token 准备目录没有调用 API；改为 700 后另建目录，旧文件没有覆盖。

## 入口

```powershell
# 默认只准备冻结文件，不联网；输入与输出都在本 checkout 外的私有目录
python scripts/query_caretaker_trial.py --cases <题集> --db <离线库> `
  --agent-id <固定身份> --output-dir <全新目录>

# 模型关闭，仅本地原路与短包回退验证
python scripts/query_caretaker_trial.py --cases <题集> --db <离线库> `
  --agent-id <固定身份> --output-dir <另一个全新目录> --run-offline

# 仅在对应问句和预算已获准后；不能从“已有 key”推断数据外发已获准

  --agent-id <固定身份> --output-dir <已准备目录> --resume --allow-query-only-api `
  --key-file <OpenAI DPAPI文件> --budget-ledger <已有OpenAI累计账本>
```
