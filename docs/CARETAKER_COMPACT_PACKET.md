# 证据包减重：重复出处只写一次

2026-11-22，对象复核 v9；承接[并存缺口与补证顺序](CARETAKER_MULTIPLE_GAPS.md)。
本节只改变本机装包和读包方式，模型提示、请求与响应 schema 不变。
仍在隔离试验分支，正式 MCP、Bot 和导入侧摘要未启用本功能。

## 为什么先处理出处开销

两道旧题中，模型选中了六条证据，但重复的长来源编号、字段名和关联窗口占用容量，
实际只能递出四条及其上下文。若直接删短纠正或冲突原话，包虽小了，证据也可能失真。

v9 新增 `backend/memory/evidence_packet.py`，以 `columnar_references_v1` 标识引用表：

- 每条引用仍保留来源、房间、说话人、记录时间、冲突组、观察指纹、截断状态和原文位置。
  相同字段值放入共享默认值；其余值按有名称的列存储。重复字符串只有确实节省字节时才用字典。
- 条目和关联窗口使用包内短编号。编号只在当前包有效，不能代替真实记录编号或取得读取权限。
  原句与证据类别不改写，也没有生成新的语义摘要。
- `expand()` 恢复原结构，包括每个出处和顺序链接。不同来源即使文字相同也保留各自引用；
  同一来源的不同摘引位置不合并。同一记录编号指向不一致来源时拒绝装包。
- 解码拒绝未知格式、悬空或未引用的来源行、非法字典索引、错误指纹格式和不完整顺序链接。
  **解码成功不等于来源可信**：后续仍通过绑定身份的只读查询核对来源、角色、时间及逐字位置。

`refine_object_shadow` 和对象试验入口使用新格式；通用筛选路径不变。
`make_brief(..., compact=False)` 保留旧结构供显式对照；评估器与整链离线评分器支持两种结构。
固定试验的代码指纹纳入新模块，旧试卷与成绩没有覆盖。

## 容量按最终装包结果判断

保留最多六项模型所选证据、六项相邻语境，**整包仍最多 12,000 UTF-8 字节**。
先按完整关联组组装、算好缺口和暂扣数量，再测量压缩出处后的最终字节数。
放不下时仍整组暂扣，不能拆散纠正前后或已知冲突两边。装包异常仍退回原安全短包。

缺口、补证顺序、完整性状态和来源限制保留；装得下不代表答得全。
小包不保证总比旧格式更小，共享表自身也有开销。未测量模型分词数，不把字节节省当成精确费用节省。
