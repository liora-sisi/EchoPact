- OpenAI 选她先前指定系列的 `gpt-5.6-sol`，不擅自替换成 GPT-6。Venice 比较对象为
  `mistral-small-3-2-24b-instruct` 的已有四房原卷，不重复调用来挑最好的一次。

  本地校验；参考答案、复核目标不发给模型。
- 这轮比较摘要任务，不是已经实现 M22 自然问句理解器。生成和查询继续独立选型。
- OpenAI 使用 Responses、低推理强度、2500 输出 token 上限（含推理）；Venice 为
  关闭 thinking、1500 输出上限。参数不同明确记录，不能称为完全同算力或同延迟。
- 无工具调用、联网检索、真实资料输入；`store=false`。这只是关闭响应存储，

- 语义复核独立于 JSON/证据结构校验。拒答、漏项、错误引用、未完成响应都不自动
  重试、不冒充正常记忆；失败稿隔离保留。

## 预算、钥匙与长期使用

专用钥匙属于当前明确授权的项目，名称 `Echo Caretaker`，长期有效；只需要模型读取
与 Responses 写入权限。这个名称/权限可以长期沿用，不因更换模型而重新申请。
本轮 **USD 0.50** 是试验程序与独立累计账本上限，不是已消费金额，也不是平台钥匙
自身的硬额度。不能据此承诺这把钥匙在其他程序中也自动受到同一费用限制。

钥匙只通过本机密码输入框加密保存，DPAPI 使用 OpenAI 独立的 provider 标记与 entropy；
不能混用 Venice 凭据。现有 Venice 账本默认上限仍为 USD 0.10，不重置、不扩张。
OpenAI 入口要求 `provider=openai`、固定 trial_id 的独立账本，才接受显式 USD 0.50 上限。

完整输出上限计算，不假设缓存折扣。四房合计 **USD 0.304348**。价格核验于
2026-11-10，优惠截至 11 月 30 日；之后付费入口在模型查询前停止，要求重新核价。
