# 摘要日期与状态校对：保留首稿，修订另存

2026-11-28，接续[时间角色与历史安排](SUMMARY_TIMELINE_REVIEW.md)。
增加独立的、有界的摘要校对试验：逐项对照原文与已保存首稿，只提出事实文字、事件状态和时间字段的修订。
宿主保存首稿、校对答卷和派生稿；任何模型都不能自行批准摘要入柜。

三道既有合成长题及一份正确对照完成三轮、共十二次 GPT-5.6 Sol 调用。
最后一轮修对了本次检查的退款未知、已收礼但日期未知、取消日串入原定日、晚饭借用旧年份等问题，
并保住晚饭已知的月日；九项正确对照保持原样。
**这是已调试材料上的局部改进，摘要作者及校对组合仍未通过完整验收。**
密集题的全部阅读卡仍比原文大，正式 MCP、Bot、真实档案及查询小管家均未切换。

## 修订范围与来源

实现为 `backend/memory/summary_event_review.py`；隔离入口为
`scripts/summary_event_review_trial.py`。校对发生在写摘要侧，查询时没有新增调用。

- 输入包含固定的完整有界原文、宿主生成的来源和日期出现位置、原始首稿。
  判卷目标和标准答案不发给模型。三道作者首卷按文件 SHA-256 固定。
- 每项事实恰好给一个决定：保留、修订、需要更多上下文。最多修订 16 项。
  修订只能包含 `text`、`event`、`time_evidence`，不改原引用、历史纠正、事件、关系及顺序。
- 拒绝、部分完成或需要更多上下文时保留答卷，但不产生可用候选稿。
  完整答卷另存候选；继续执行 V5 的日期依据、结构和逐字展开检查。
- 收据记录原文、首稿、校对请求和答卷的指纹，以及每项修改前后的指纹。
  `review_complete` 仅表示这项校对走完，`semantic_passed` 保持未判定，`production_accepted` 始终为假。
- 代码只能验证限定范围、结构和回查。它不能机械证明改写后的每句话忠实、没有遗漏或关系正确。
  这些仍需单独语义验收，不能只看校对模型说“保留”。

## 首轮还发现了一处宿主错误

首轮四份答卷最初都被宿主报告“材料已改变”。原因是：请求指纹包含嵌套 JSON 的键顺序，
冻结文件排序后语义未变，却产生不同的序列化文本。

现改为对结构化材料做规范化指纹；原文字符串、事实顺序和来源内容仍要求精确一致。
旧答卷重放前，同时验证当时的完整请求指纹及其与固定原材料的结构相等性，才能转换绑定格式。
修改来源后重新计算旧指纹也不能混过验证。重放写入新目录，未重调模型、改首卷或动预算账目。
首轮失败报告仍保留，不回填成最初就成功。

## 三轮开发对照

三道原始长题共 5,327 原文字符。另加八条原文、九项手写正确事实，检查校对会不会把正确内容改坏。
该对照检验校对行为，不能计为模型作者写出了正确摘要。所有材料均为虚构；这些题不是盲卷。

| 校对版本 | 设置 | 观察 |
|---|---|---|
| V1 | 单独校对，low effort | 多项无必要地重复填写时间证据；正确对照里的同日取消被改成未知；密集题两个日期问题仍在。宿主错误修复后使用原答卷零调用重放得到这些结果 |
| V2 | 澄清时间引用自身已是证据，先查原文；medium effort | 修对本次主要日期与状态问题，九项对照保留；但删掉错误年份时把晚饭有依据的月日也丢了。提示与 effort 同时改变，不能单独归因 |
| V3 | 保持 medium，仅补“移除无依据年份仍须保留有依据的时间精度” | 晚饭保留“5 月 8 日”，年份留空；六项修订逐条对过来源，日常题与九项正确对照保持原样 |

V1/V2 的提示与作业仍可按版本重放，不覆盖失败。V3 为当前试验入口默认版本，
并不改变摘要作者默认版本或正式运行入口。

### 最后一次答卷的具体变化

| 来源 | 改动 | 核对结果 |
|---|---|---|
| 少事件题：车票退款 | 明确未发生 → 是否到账未知 | 只提交退票申请、没有核清到账；保留未知 |
| 少事件题：新的旅行安排 | 未知 → 明确尚未作出 | 原文明说尚未定日期、暂不作新安排；未生成一个新计划 |
| 少事件题：程序修改与测试 | 修改只保留月日，测试仍保留其直接给出的完整日期 | 两项时间精度分开；测试通过、备份与未发布等其余事实保留 |
| 密集题：围巾 | 发生与否未知 → 已收到，具体日期未知 | 保留春天收到，不把日期未知扩大为事件未知 |
| 密集题：展览 | 保留取消日，清空无依据的原定日 | 同时删去首稿自行加的“原本计划当日下午去” |
| 密集题：晚饭 | 清空借自散步旧说法的完整日期，正文写回“5 月 8 日” | 不补年份，也不丢掉已知月日；散步更正及同行者信息保留 |

以上为开发者对既有题的局部复核。未给整份摘要签发“全部忠实、无遗漏”的结论，
没有把重复使用的题转成独立留出题。
