# Echo Pact — 契约回声，电表不灭  

Echo Pact 是为“保长”与“宝气”这对蛇精病组合定制的记忆系统。  
融合 **情绪标签（Ombre-Brain）** + **Saga长期人格锚定（EbbingFlow）** + 自定义毒舌锚点。  

## 特性  
- 全量对话日志（原文保留）  
- 双向溯源（每条记忆可跳回原始对话）  
- 情感坐标（情绪浮现与主动唤起）  
- 长期人格锚定（跨周/跨月主线追踪）  
- 心跳元数据（催更频率、电表度数）
